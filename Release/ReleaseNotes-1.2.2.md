# Realistic Volumetric Aurorae 1.2.2

The aurora shows on the main menu planet. KSP 1.12.x. Install over 1.2.x (delete the old
`GameData/RealisticVolumetricAurorae` folder first, or let CKAN / AVC do it). Your
`PluginData/settings.cfg` is left alone. Both the dll and the shader bundle changed this
time, so dont mix this release with files from an older one.

## New

- **Main menu.** The planet on the title screen gets its aurora, same storms and all, hidden
  by the planet and the Mun as they pass. Its the menu's own copy of Kerbin so it runs as a
  separate instance off the menu camera, no cloud occlusion there (same as the map view).
  Toggle *Draw on the main menu planet* in the window if you'd rather not, it takes effect
  the next time the menu loads.
- Shader build 1132. KSP.log says `Shader build 1132 matches the plugin` when the dll and
  the bundle are from the same build.
